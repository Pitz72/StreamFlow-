### 🔴 Fix Critico: Compilazione Main Process in Dev Mode

- **Problema**: Lo script `electron:dev` avviava Vite (renderer) ed Electron in parallelo, ma **non compilava mai** il Main Process (`src/main/`) né il Preload (`src/preload/`). Electron caricava un `dist/main/main.js` stale dalla build precedente, rendendo invisibili tutte le modifiche al backend (IPC, StreamManager, FFmpeg).
- **Causa Root**: Lo script usava solo `concurrently` per Vite + Electron, senza un passaggio `tsc` preventivo.
- **Soluzione**: Aggiunto `npm run build:main &&` come primo step dello script `electron:dev`.
- **Prima**:
  ```json
  "electron:dev": "concurrently -k \"...npm run dev\" \"...electron .\""
  ```
- **Dopo**:
  ```json
  "electron:dev": "npm run build:main && concurrently -k \"...npm run dev\" \"...electron .\""
  ```
- **Effetto**: Ora ogni `npm run electron:dev` garantisce che il Main Process e il Preload siano compilati dal sorgente TypeScript corrente prima dell'avvio di Electron.

### Pulizia e Correzioni Minori (da Audit Forense)

Le seguenti correzioni sono state applicate durante l'audit forense della codebase:

1. **Versione UI sincronizzata**: L'header UI mostrava `v0.0.8` — aggiornata a `v0.1.1`.
2. **File `audio.ts` ripulito**: Rimossi handler IPC duplicati (`start-stream`, `stop-stream`) che potevano confliggere con quelli in `ipcp.ts`. Il file ora contiene solo un commento di reindirizzamento.
3. **Campo `bitrate` rimosso**: L'interfaccia `StreamConfig` in `ffmpeg-manager.ts` definiva un campo `bitrate?: string` mai utilizzato (il valore è hardcodato a `128k`). Rimosso per evitare confusione.
4. **Status bar dinamica**: Il `SettingsPanel` ora legge `streamStatus` dallo store Zustand e mostra stato e colore contestuali (Ready/Connecting/ON AIR/Error) invece del testo statico "Ready".
5. **Commenti di debug rimossi**: Eliminate ~50 righe di commenti di ragionamento/debug da `App.tsx` e `VuMeter.tsx`.
6. **Documentazione corretta**: Aggiornato `ARCHITECTURE.md` con la specifica corretta sull'encoding (canali da sorgente, non forzato "Stereo") e aggiunta nota VU Meter mono.
