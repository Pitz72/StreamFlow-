### 🟢 Fix Cosmetici e Legacy (L1, L2, C1)

1. **[L1] Rimozione del `require` nel Preload Bridge**: 
Il file `src/preload/index.ts` dichiarava il modulo `electron` tramite un vecchio import CommonJS `const { contextBridge, ipcRenderer } = require('electron');`. Sebbene tollerato dal Node environment, rompeva lo standard formale di Vite e TS che viaggiavano a stretto ESModules ES2020.
Sostituito formamente con l'idiomatico `import { contextBridge, ipcRenderer } from 'electron';`. Il layer TypeScript garantisce retrocompatibilità via compilazione senza errori TS2304.

2. **[L2] Eliminazione file morto `audio.ts`**:
Trovato ed eliminato un the file obsoleto `src/main/audio.ts` contenente logica commentata derivante da the archeologia delle prime patch. L'intero sistema audio passa esclusivamente da `ffmpeg-manager.ts` protetto e interfacciato nel `ipcp.ts`.

3. **[C1] Pulizia Commenti Morti `Timer.tsx`**:
Rimosso un blocco testuale lungo relativo a ipotetici refactoring *("Optional: Reset on stop? Or pause?")* e commenti boilerplate dal ramo `else` dello scatto Timer. Il codice ora è The self-documenting.
