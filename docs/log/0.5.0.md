## Modifiche per B1 — Profili server

### `src/renderer/store/useStore.ts`
- Aggiunta interface `ServerProfile` (esportata): `{ name, host, port, mount, icecastUser, bitrate }` — password esclusa intenzionalmente.
- Aggiunti al store: `profiles: ServerProfile[]`, `saveProfile(name)`, `loadProfile(name)`, `deleteProfile(name)`.
- `saveProfile` usa upsert per nome: se il nome esiste già lo sovrascrive, altrimenti aggiunge.
- `profiles` persistito in localStorage via `partialize`.
- Aggiunti anche: `azuraCastUrl`, `azuraCastApiKey` (session-only, non persistito), `azuraCastStationId`, `setAzuraCastContext`.

### `src/renderer/components/SettingsPanel.tsx`
- Nuova sezione "Server Profiles" in cima alla lista campi.
- Dropdown `<select>` con i profili salvati + opzione "— Seleziona profilo —".
- Selezione dal dropdown → carica immediatamente il profilo in `streamConfig`.
- Pulsante "+ Salva profilo" → espande inline input per nome + tasto ✓ (Enter) + ✕ (Escape/cancel).
- Se un profilo è selezionato, appare pulsante "Elimina" che chiama `deleteProfile`.

### `src/renderer/components/AzuraCastWizard.tsx`
- `apply()` chiama ora anche `setAzuraCastContext(url, apiKey, selectedStationId)` per salvare il contesto nello store, necessario per il pannello Cover Art.

## Modifiche per B2 — Cover Art

### `src/renderer/components/CoverArtPanel.tsx` (nuovo)
- Pannello collassabile (collapsed: bottone "Cover Art — Carica su AzuraCast").
- Zona drag&drop / click per selezione file (accept: `image/*`).
- Resize lato renderer via Canvas API: max 1000×1000px, JPEG 92%, proporzionale.
- Preview inline dell'immagine ridimensionata.
- Messaggio warning se il contesto AzuraCast (url/apiKey/stationId) non è configurato.
- Bottone "Carica su AzuraCast" → chiama `window.electronAPI.azuraCastUploadArt(...)`.
- Feedback visivo: idle / uploading / success (verde) / error (rosso).

### `src/main/azuracast/azuracast-api.ts`
- Aggiunta funzione `uploadStationArt(baseUrl, apiKey, stationId, imageBase64)`.
- Implementazione manuale multipart/form-data con `http`/`https` Node.js (coerente con il resto del file).
- Timeout 15s; gestione errori HTTP con status code e body troncato.
- `imageBase64` è la stringa base64 pura (senza prefisso `data:...`).

### `src/main/ipcp.ts`
- Aggiunto handler `azuracast-upload-art` → chiama `uploadStationArt`, restituisce `{ ok, error? }`.

### `src/preload/index.ts`
- Aggiunto `azuraCastUploadArt` al contextBridge.

### `src/renderer/env.d.ts`
- Aggiunta firma `azuraCastUploadArt` a `ElectronAPI`.

### `src/renderer/App.tsx`
- Import `CoverArtPanel`.
- Aggiunto `<CoverArtPanel />` nel main content area, sotto `<NowPlayingPanel />`, racchiuso in `<div className="w-full max-w-sm">`.
- Versione header aggiornata da `v0.4.0` a `v0.5.0`.

### `package.json`

## Note tecniche

- Il resize avviene nel renderer process (browser context) per accedere a Canvas API senza dipendenze aggiuntive.
- `azuraCastApiKey` non viene persistito per sicurezza: si azzera al riavvio. L'utente deve ripassare dal Wizard per ripristinarlo.
- Il boundary multipart usa `----StreamFlowBoundary{timestamp}` per unicità.
- L'endpoint AzuraCast per l'art è `POST /api/station/{id}/art` (non PUT).
