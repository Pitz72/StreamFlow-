# Runtime StreamFlow v0.1.7 Log

## Data: 2026-03-05
## Versione: 0.1.7 (Medium Fix: UI/CSS Cleanup)

### Stato: IMPLEMENTED
Risolti i bug medi (M1 e M2) riguardanti la spazzatura CSS di defaut e le dipendenze inutili lasciate da test precedenti con componenti UI.

### 🟡 Fix Medio M1: Vite Default CSS
Il file `App.css` generato di default da Vite era rimasto nel progetto. Questo includeva padding, margin e text-alignment globali che confliggevano silenziosamente con Tailwind, rendendo il sizing imprevedibile.
- **Azione**: `App.css` è stato brutalmente eliminato fisicamente dal disco.

### 🟡 Fix Medio M2: Shadcn UI CSS Variables & Dependencies
Un precedente tentativo di usare Shadcn UI aveva infettato il progetto. 
- `index.css` era ricolmo di dozzine di variabili CSS `--primary`, `--border`, `--radius` esposte in `:root` e nel layer scuro `.dark`. Tutto ciò pompava il payload CSS ed era scollegato dai temi di default di Tailwind (che il progetto ora usa).
- `tailwind.config.cjs` conteneva estensioni complesse di animazioni radix.
- `package.json` manteneva 5 dipendenze fantasma: `class-variance-authority`, `clsx`, `lucide-react`, `tailwind-merge`, `tailwindcss-animate`.

- **Azione**: 
  1. Spazzato via tutto il blocco `:root` e `.dark` dal file `index.css`, mantenendo i nudi `@tailwind`.
  2. Rimosso codice cross-compat dal base layer di index.
  3. Pulito ed essenzializzato il `tailwind.config.cjs` togliendo il plugin `tailwindcss-animate` e i temi personalizzati.
  4. Cancellate dal `package.json` le 5 dipendenze legate a questi stack, riducendo di svariati MB il peso del `node_modules` e ripulendo il package tree (`npm install` runnato per pulizia finale).
