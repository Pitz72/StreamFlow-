# v0.5.4 — Rimozione feature Cover Art

## Motivazione

La feature Cover Art (B2, introdotta in v0.5.0) era basata sull'endpoint inesistente `POST /api/station/{id}/art` di AzuraCast → 405 Method Not Allowed dall'inizio.

Gli endpoint reali di AzuraCast per artwork sono:
- `POST /api/station/{id}/files/{mediaId}/art` → cover di un singolo file media (non applicabile a uno stream live)
- `POST /api/station/{id}/streamer/{id}/art` → immagine profilo del DJ

AzuraCast gestisce già il caso d'uso reale lato server:
- Quando un DJ è ON AIR, mostra automaticamente l'immagine del profilo streamer caricata in admin UI.
- In assenza di art associata, fa lookup automatico su MusicBrainz/Last.fm dal titolo+artista dei metadata Icecast (che StreamFlow invia correttamente dalla v0.5.3).

Una feature "carica cover dall'app StreamFlow" duplicherebbe l'UI admin senza valore aggiunto. **Desistere è la scelta corretta.**
