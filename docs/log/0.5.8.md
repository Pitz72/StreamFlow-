# v0.5.8 — Hardening completo post-audit (gravi + medie + lievi)

## Contesto

Dopo la v0.5.7 (3 gravissime), questa versione chiude **tutto il resto dell'audit** `docs/AUDIT-2026-07-13.md`: le 3 gravi rimanenti (S2 mitigata/documentata, S4, S5), le 9 medie e le 14 lievi.

## Gravi

- **S4 — finestra macOS "morta" dopo activate**: `initializeIpc` è idempotente — `ipcMain.handle` registrati una sola volta (flag modulo), `boundWindow` + `streamManager.setMainWindow()` + `did-finish-load` ricollegati a ogni chiamata. `main.ts` la invoca in ogni `createWindow()`; rimosso il flag `ipcInitialized`.
- **S5 — doppio GO**: `startInFlightRef` (useRef, sincrono) in `App.tsx`; rilasciato dal primo evento status IPC o da un fallback di 3s; rilascio esplicito sui percorsi di validazione fallita.
- **S2 — credenziali in command line (rischio accettato)**: limite strutturale di FFmpeg CLI (non legge headers da stdin/env). Documentato con commento nel codice; mitigazione `windowsHide: true` su tutti gli spawn/exec.

## Medie

- **M1 — VU stereo reale**: `useAudioVisualizer(deviceId, enabled)` ora restituisce `{left, right}` da un'unica pipeline (`MediaStreamSource → ChannelSplitter → 2 AnalyserNode`); input mono rilevato via `track.getSettings().channelCount` e duplicato su L/R. `VuMeter` è diventato presentazionale (prop `volume`); la pipeline vive in `App.tsx`, una sola per l'app (prima erano due complete).
- **M2 — microfono sempre acquisito**: la pipeline è attiva solo con finestra visibile (`document.visibilitychange` → prop `enabled`); app minimizzata = mic rilasciato, indicatore privacy OS spento.
- **M3 — injection metadata**: `buttEncode` rimuove i control char (CR/LF spezzavano la richiesta HTTP raw) e percent-encoda `%` `#` `?` oltre a spazio/`&`; il mount viene ripulito da whitespace/control char (resta non-encoded per il `/` letterale che serve a Liquidsoap).
- **M4 — CSP**: produzione `script-src 'self'` (niente unsafe-*); plugin Vite `streamflow-dev-csp` (apply: 'serve') rilassa solo in dev per il preamble react-refresh. Verificato: build di produzione contiene la CSP stretta, dev server serve quella rilassata.
- **M5 — sandbox renderer**: `sandbox: true` (il preload usa solo contextBridge/ipcRenderer, sandbox-compatibile; FFmpeg è spawnato nel main). Aggiunti `setWindowOpenHandler` (deny) e guard `will-navigate` (solo localhost:5173 in dev / file:// in prod).
- **M6 — kill sincrono al quit**: `stop(sync)` → `killCurrentProcess(sync)` usa `execSync(taskkill)` quando chiamato da `cleanupIpc` (before-quit): un exec asincrono poteva non partire mai prima della morte del main.
- **M7 — redirect AzuraCast**: `fetchJson` segue 301/302/303/307/308 via header `location` (relativo o assoluto), max 3 hop.
- **M8 — rejection IPC**: try/catch in `handleSend` (NowPlayingPanel), `loadStations`/`loadDetail` (wizard) con messaggio "Errore IPC: …" invece di UI bloccata.
- **M9 — single instance**: `app.requestSingleInstanceLock()`; la seconda istanza esce, la prima riceve focus/restore.

## Lievi

- **L1** versione centralizzata: `__APP_VERSION__` (define Vite) nell'header UI, `app.getVersion()` nello User-Agent metadata. Dichiarazione ambient in `env.d.ts`.
- **L2** `-ab` → `-b:a`.
- **L3** device listing: timeout 10s con kill del processo + `[...new Set(devices)]`.
- **L4** detection errori con regex `\b40[134]\b|Connection refused|Unauthorized|access denied|I\/O error` (niente falsi positivi da "size= 401kB").
- **L5** metadata: al timeout, se `rawResponse` contiene una status line parsabile viene valutata come risposta vera.
- **L6** `StreamManager.start()` ritorna boolean; `ipcp` imposta la config metadata solo se `started`.
- **L7** timer congelato su stop/drop (durata ultima sessione visibile), azzerato al GO successivo.
- **L8** listener status IPC stabile: metadata correnti letti da `metadataRef` invece che dalle deps dell'effect.
- **L9** NowPlayingPanel: `resetTimerRef` con cleanup su unmount; guard `sendStatus === 'sending'` (Enter non duplica più gli invii).
- **L10** `tsconfig.main.tsbuildinfo` untracked, `*.tsbuildinfo` in .gitignore.
- **L11** rimossi favicon `/vite.svg` (inesistente) e `assets/react.svg` (file vuoto); `<title>` → "Runtime StreamFlow".
- **L12** lib `DOM` rimossa da `tsconfig.main.json` (compila pulito).
- **L13** validazione device allo start: `getAudioDevices()` consultato prima di `startStream`, messaggio esplicito se il device persistito non esiste più (skip se la lista è vuota, es. piattaforme non-Windows).
- **L14** `Modal` prop `closeOnBackdrop` (default true); Configurazione usa `false`.
