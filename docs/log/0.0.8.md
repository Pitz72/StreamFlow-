# Runtime StreamFlow v0.0.8 Log

## Data: 07/02/2026
## Versione: 0.0.8 (Patch: HTTP PUT Implementation)

### Stato: IMPLEMENTED
Riscritto completamente il motore di streaming `StreamManager` per implementare fedelmente il protocollo di connessione di **BUTT** (Broadcast Using This Tool).

### Modifiche Core (Backend - ffmpeg-manager.ts)

1.  **Direct HTTP PUT**:
    - Abbandonato definitivamente `icecast://`.
    - Implementata connessione diretta via `HTTP PUT` all'URL del server.
    - URL Target: `http://user:password@host:port/mount`.
    - Se il Mount Point è `/` o vuoto, viene forzato lo slash finale.

2.  **Argomenti FFmpeg Ottimizzati**:
    - `-method PUT`: Metodo HTTP per l'invio dello stream.
    - `-content_type audio/mpeg`: Header obbligatorio per il riconoscimento MP3.
    - `-f mp3`: Forzatura formato contenitore.

3.  **Compatibilità Mantenuta**:
    - Mantenuta la logica di pulizia nomi device per Windows (dshow).
    - Mantenuta l'integrazione IPC (`mainWindow`) per aggiornare lo stato (ON AIR / Timer) nell'interfaccia.
    - Mantenuta la mappatura dei campi di configurazione (`inputDeviceName` -> `inputDevice`).

### Note
Questa versione punta a risolvere definitivamente i problemi di connessione con server DJ (AzuraCast) che richiedono un mount point di root.
