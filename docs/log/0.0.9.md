# Runtime StreamFlow v0.0.9 Log

## Data: 2026-02-08
## Versione: 0.0.9 (Critical Patch: HTTP Chunked & Process Management)

### Stato: IMPLEMENTED
Risolti problemi critici di compatibilità con alcuni server Icecast/Shoutcast e migliorata la gestione dei processi "zombie" su Windows.

### Modifiche Core (Backend - ffmpeg-manager.ts)

1.  **Disabilitazione Chunked Encoding**:
    - *Problema*: Alcuni server Icecast/AzuraCast non accettano stream HTTP con `Transfer-Encoding: chunked`, interrompendo la connessione immediatamente.
    - *Soluzione*: Aggiunto flag `-chunked_post 0` agli argomenti FFmpeg.
    - *Dettaglio*: Questo forza FFmpeg a inviare i dati senza l'header chunked, migliorando drasticamente la compatibilità.

2.  **Gestione Processi Windows (Taskkill)**:
    - *Problema*: Il semplice `.kill()` di Node.js su Windows spesso lasciava processi `ffmpeg.exe` orfani in background, bloccando la scheda audio.
    - *Soluzione*: Implementato `exec('taskkill /pid ... /f /t')`.
    - *Funzionamento*: Forza la chiusura dell'intero albero dei processi associati a FFmpeg, garantendo il rilascio del dispositivo audio.

3.  **Normalizzazione Mount Point**:
    - *Fix*: Se il mount point è vuoto o mancante, viene forzato a `/`. Questo è richiesto specificamente dalle configurazioni "DJ Mode" di AzuraCast che montano lo stream alla root.
