# Runtime StreamFlow v0.1.8 Log

## Data: 2026-03-05
## Versione: 0.1.8 (Medium Fix: Device Name Mapping dshow)

### Stato: IMPLEMENTED
Risolto un bug medio/critico (M3) che rischiava di bloccare la connessione audio all'origine a causa di discrepanze tra i nomi hardware (`dshow`) e quelli riportati dalle Web API (`navigator.mediaDevices`).

### 🟠 Fix Medio M3: Il Vero Nemico "DSHOW"

#### Diagnosi
`useAudioDevices.ts` utilizzava il classico `navigator.mediaDevices.enumerateDevices()` di Chrome (Electron Renderer) per ottenere la lista microfoni e popolare la tendina.
Di conseguenza, al Main Process (Node.js) veniva inviato un nome come `Microfono (Realtek Audio)`.
Tuttavia, `ffmpeg.exe` usa l'API di cattura di basso livello di Windows, DirectShow (`dshow`), i cui Root Names sono spesso differenti o molto più estesi. 
Di conseguenza, FFmpeg restituiva `Could not find audio device with name...` causando un errore fatale allo start.
La vecchia mitigazione consisteva in una blanda regex Replace `inputDeviceName.replace(/^(Default|Communications) - /, '')` in `ffmpeg-manager.ts` che cercava invano di "indovinare" il formato dshow, fallendo per l'80% delle schede audio.

#### Soluzione Applicata
1. **FFmpeg come Fonte della Verità**: Al Posto di chiedere a Chrome quali dispositivi ci sono, chiediamo a FFmpeg. È stato introdotto il metodo `StreamManager.getWindowsAudioDevices()` in `ffmpeg-manager.ts`. Questo metodo spawna FFmpeg in modalità sonda (`ffmpeg -list_devices true -f dshow -i dummy`).
2. **Parsing Diretto**: Legge in parallelo lo stderr `DirectShow audio devices` ed estrae con RegEx la stringa testuale esatta contenuta le doppie virgolette.
3. **Ponte IPC**: Implementato handler IPC nel Main process, e un espositore in `preload/index.ts` chiamato `window.electronAPI.getAudioDevices()`.
4. **React Hook**: Modificato `useAudioDevices.ts` in modo tale che al `useEffect` il componente chieda la lista al back-end invece che al browser (senza più necessità di permissions). Ora l'array `devices` contiene etichette garantite per combaciare ad personam con dshow.
